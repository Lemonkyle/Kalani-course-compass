# 课程按钮动画与选课例外更新

本次按项目所有者反馈，恢复课程详情内添加按钮的缩放、文字滑动及绿色“✓ Added!”状态，并让年级与主科年度负担成为提醒。

## 选课行为

- ELA1 可以在 12 年级规划：显示常规年级说明，选择 Add Anyway 即可添加。若同年已有另一门英语课，合并显示年度负担提醒。
- 英语、数学、社会学习、科学通常一年 1 学分；按实际课程学分累计，不按课程条目数量判断，也不使用毕业学分来代替课程负担。
- 夏威夷历史＋民主、经济＋心理学、经济＋AP 宏观经济均为 0.5＋0.5，不触发主科超量提醒。原有先修与并修提示独立保留，仍可确认继续添加。
- 超过上述常规主科负担只提醒；转学、补课等例外可以加入并保存。课表中保留可展开的负担提示。
- 课程页与课表搜索共用提醒和确认界面；自定义课程在提交前展示同样的负担说明；模板中的年级例外不再作为阻止应用的错误。
- 不可重复课程的重复记录、不可用课程和原有年度总容量 14 仍作基本保护。需要把已有课程移到另一年级时，先从原年级移除。

## 动画与操作

按钮变化由实际课表状态驱动，不延迟写入，也不在动画计时器中修改数据。支持鼠标、触屏、Enter/Space；遵循系统减少动态效果设置。课表内搜索框移除了不可动画的 auto 间距过渡。

## 验证范围

41 项自动测试覆盖语言学分、转学补课、半学分组合、四类主科提醒、先修与年级提醒合并、模板以及现有后台校验；生产构建通过。浏览器检查覆盖课程详情与课表搜索的取消、继续添加、移除及保存后显示。
